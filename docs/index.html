calvin — text in the Calvin S box-drawing font

Calvin S is a box-drawing alphabet built from Unicode line characters, the kind a text-art generator renders banner text in. This converts any text into it, and into BlackboardBold, as you type.

The same converter is a Go library and a command-line filter — echo "Hello, World!" | calvin — so it can label terminal output, README headings or commit messages. This page is it compiled to WebAssembly.

Source code: github.com/0magnet/calvin. More Go and WebAssembly projects: magnetosphere.net/software.
